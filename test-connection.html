🔍 Test Koneksi Google Apps Script

📊 Hasil Test:

Klik tombol test untuk melihat hasil...

📝 Cara Menggunakan:

  1. Paste URL Google Apps Script Anda di kotak input
  2. Klik "Test getDesa" untuk test data desa
  3. Klik "Test getPrograms" untuk test data program
  4. Lihat hasil di kotak bawah
  5. Jika ada error, screenshot dan kirim ke developer

✅ Hasil yang Diharapkan:

Status harus "success" dan data harus sesuai dengan spreadsheet Anda

{
  "status": "success",
  "message": "Success",
  "data": {
    "id_desa": 1,
    "nama_desa": "Nama Desa Anda",
    ...
  }
}
